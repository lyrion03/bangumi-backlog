# bangumi动画补标工具

**bangumi-backlog · 让每一次补番都有迹可循**

不管你是动画老资历婆罗门，还是新入宅不久的萌新，都能使用该工具进行快速补标。找到漏标的作品，沿着系列前作、续作，一次整理你的追番记录。

**[下载最新 Release](https://github.com/lyrion03/bangumi-backlog/releases/latest)**

## 下载与启动

1. 下载 Release 的 **Assets** 中的 `bangumi-backlog-v1.0.0.zip` 并完整解压，请勿下载 Source code。
2. 安装 [Node.js](https://nodejs.org/zh-cn/download)（22.12+ 或 24 LTS，已安装可跳过）。
3. Windows 双击 **`START-WINDOWS.cmd`**；macOS / Linux 在解压目录运行 `node serve.mjs`。
4. 浏览器打开 **http://127.0.0.1:4173**，使用期间保持启动窗口开启。

无需安装项目依赖或编译；不要直接双击 `web/index.html`。

## 开始补标

1. 自行配置科学上网，确保能访问 Bangumi。
2. 进入「同步中心」，[获取个人令牌](https://next.bgm.tv/demo/access-token)，粘贴后「验证并连接」，工具会自动拉取收藏。
3. 回到「发现与补标」筛选、标记作品，或点击「发现系列 · 去补标」批量整理前作与续作。

**自动推送默认开启**，标记后自动同步，可在同步中心关闭。拉取或手动推送遇到状态冲突时，会询问保留本地还是云端。

## 主要功能

- 单部快捷标记、多选批量补标、主线系列补标。
- 名称、年份、季度、标签与 NSFW 筛选，热度 / 排名 / 日期排序。
- 隐藏已整理、自动翻页、每页 10 / 20 部及系列缓存。
- 收藏与单集进度管理，JSON 导入导出备份。

数据保存在浏览器中，请固定使用同一浏览器和地址，并定期导出备份。标记「看过」默认补齐已播正篇；「不感兴趣」仅在本地生效。
